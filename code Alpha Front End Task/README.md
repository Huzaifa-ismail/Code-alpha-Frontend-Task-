# Frontend Projects Collection

This repository contains four frontend web development projects completed as part of the Code Alpha Internship Program. These projects were developed to strengthen practical skills in HTML, CSS, and JavaScript while creating interactive and responsive web applications.

## Projects Included

### 1. Portfolio Website
A personal portfolio website designed to showcase skills, projects, achievements, and contact information.

### 2. Image Gallery
A responsive image gallery that displays images in an organized and visually appealing layout.

### 3. Calculator
A functional calculator capable of performing basic arithmetic operations with a clean user interface.

### 4. Music Player
A web-based music player with features such as play, pause, next, previous, and volume controls.
